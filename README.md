# Memory — AR-сайт

## Структура

```
index.html            страница (текст FR/EN, разметка)
config.js             ← ВСЕ НАСТРОЙКИ: файлы, размер и положение объекта
css/style.css         оформление
js/app.js             логика (AR, 3D-просмотр, камера) — править не нужно
content/
  model.glb           3D-объект (glTF binary)
  marker.mind         скомпилированный маркер (то, что распознаёт телефон)
  marker.jpg          исходное фото маркера (для печати и теста, сайтом не загружается)
tools/
  marker-compiler.html   сборка marker.mind из нового фото (в браузере)
  model-source/          скрипты, которыми сделан текущий шар
```

## Заменить маркер (фото осколков)
1. Сфотографируйте чёрный квадрат с осколками строго сверху, при выставочном свете, без бликов.
   Обрежьте фото по краям квадрата.
2. Откройте `tools/marker-compiler.html` **через сервер** (см. «Проверка на компьютере») или на опубликованном сайте:
   `https://ваш-сайт/tools/marker-compiler.html`.
3. Выберите фото → «Собрать маркер» → скачайте `marker.mind` и `marker.jpg`.
   Красные точки на превью показывают, за что цепляется трекинг: чем их больше и равномернее, тем лучше.
4. Положите оба файла в `content/` с заменой. Если имя файла другое — поменяйте `marker.file` в `config.js`.

## Заменить 3D-объект
1. Экспортируйте модель в **glTF Binary (.glb)**, текстуры внутри файла (Blender: File → Export → glTF 2.0, формат «glTF Binary»).
   Ось «вверх» — Y (по умолчанию в Blender так и есть). Желательно до ~5 МБ, текстуры до 2048 px.
2. Положите файл в `content/model.glb` (или поменяйте `model.file` в `config.js`).
3. Масштаб и центр подбираются автоматически: самая большая сторона объекта = `model.size` от ширины маркера.
4. Если объект смотрит «не той стороной» — поверните его через `model.rotation` (градусы).

## Настройки в config.js
- `model.size` — размер объекта относительно ширины маркера (0.38 ≈ треть квадрата).
- `model.position` — где висит центр объекта: `x/y` вдоль маркера, `z` — высота над ним.
- `spinSeconds`, `float`, `shadow` — вращение, покачивание, тень в AR.
- `viewer.angle` — угол камеры в 3D-просмотре на главной странице.
- `hint` — подсказка в режиме камеры.

## Публикация
Камера и загрузка модели работают **только по https** с сервера. Если открыть `index.html`
двойным кликом (адрес начинается с `file://`), модель не загрузится и камера не включится —
сайт покажет об этом предупреждение.
- Netlify Drop (app.netlify.com/drop): перетащить папку целиком.
- Или GitHub Pages / Vercel / свой хостинг с https.

## Проверка на компьютере
В папке сайта выполнить `python3 -m http.server 8000` и открыть http://localhost:8000.
(localhost браузеры считают безопасным, камера ноутбука тоже работает.)
Для теста AR дома распечатайте `content/marker.jpg` или покажите его на другом экране.

## Браузеры
- iPhone: Safari, Chrome, Firefox, Edge (iOS 14.3+).
- Android: Chrome, Firefox, Samsung Internet, Edge.
- Встроенные браузеры Instagram / Facebook / TikTok камеру не дают — сайт это распознаёт
  и просит открыть страницу в Safari или Chrome. QR-код рядом с работой открывается
  камерой телефона сразу в обычном браузере — это лучший вариант.

## GitHub Pages
1. Создайте репозиторий и загрузите в его корень всё содержимое этой папки (включая файлы `CNAME` и `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Файл `CNAME` уже содержит `memory2019.com`. У регистратора домена добавьте DNS-записи:
   - четыре A-записи для `memory2019.com`: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153;
   - CNAME-запись `www` → `<ваш-логин>.github.io`.
4. Когда домен заработает, в Settings → Pages включите «Enforce HTTPS» (без https камера не включится).
